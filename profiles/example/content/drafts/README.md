# Borradores

Contenido en progreso. Un archivo `.md` por pieza.

Mira `2026-01-15-ejemplo-borrador.md`: es una pieza de ejemplo con el
frontmatter y la estructura que se espera. Cópiala para empezar una nueva.

Convención de nombre: `YYYY-MM-DD-slug.md`

Al publicar, la pieza se mueve a `../published/`. La carpeta es la que
manda sobre el estado.
