# Style library

Ten named directions to anchor a vague brief. When the ask is "make it pop"
or "I don't know what style," pitch 2-3 of these from *different* families
(don't offer three flavors of minimalist) and let the user pick before
touching any template code. Each entry is specific enough to translate
directly into type/palette/layout decisions — that specificity is the point;
a vague style name is as useless as no style name.

---

### Swiss Editorial
- **Feeling:** Confident, orderly, a little cold in a good way — like a
  well-run newspaper masthead, not a startup pitch deck.
- **Type:** A single grotesque sans (Helvetica/Neue Haas/Inter at its most
  disciplined) carrying huge weight contrast — very bold titles against very
  light body weight. No second typeface needed; the contrast comes from
  weight and size, not font-pairing.
- **Palette:** Near-monochrome (black/white/one warm off-white) plus exactly
  one accent color used only for the single most important element per slide
  (a rule, a number, a category tag).
  Never both.
- **Layout:** Strict column grid, generous margins, left-aligned text blocks
  (rarely centered). Content sits in a grid it visibly respects.
- **Signature move:** A thin horizontal or vertical rule that structurally
  separates sections — not decorative, load-bearing to the layout.
- **Avoid:** Rounded corners, drop shadows, anything soft — softness reads as
  "not Swiss" instantly.

### Bauhaus Geometric
- **Feeling:** Playful but structural — primary shapes doing real
  compositional work, not clip-art.
- **Type:** Geometric sans (Futura-alikes) for titles, paired with a plain
  workhorse for body so the geometric face stays special.
- **Palette:** Primary triad (red/yellow/blue) plus black — used as flat
  fields, never gradients, never tints.
- **Layout:** Diagonal or off-grid placement of a title against a rigid
  underlying grid — tension between the strict grid and one element that
  breaks it.
- **Signature move:** A large flat geometric shape (circle, triangle, quarter-
  circle) anchoring one corner, functioning as a container or background
  field for a key number/word.
- **Avoid:** More than 3 shapes per slide, pastel versions of the primaries
  (defeats the point — Bauhaus color is saturated, not soft).

### Kenya Hara Emptiness
- **Feeling:** Quiet, expensive-feeling, unhurried — the opposite of a feed
  that's shouting for attention, which is exactly why it stops a scroll.
- **Type:** A single restrained serif or refined sans, small, set with
  generous line-height. Type is deliberately not the loudest thing on the
  slide.
- **Palette:** Near-white background, one desaturated color, huge amounts of
  negative space treated as a design element rather than "unused area."
- **Layout:** Content occupies a small fraction of the canvas — think 20-30%
  of the frame actually has marks on it. Off-center placement (rule-of-thirds,
  not dead-center) does the compositional work that decoration would do
  elsewhere.
- **Signature move:** One small, precise object or line of type placed far
  from center, with everything else left empty on purpose.
- **Avoid:** Filling the canvas out of a feeling that empty space is
  "unfinished." The emptiness IS the design here — resist the urge to add
  "just one more thing."

### Dieter Rams Industrial
- **Feeling:** Honest, functional, engineered — every element present
  because it does a job, nothing there to look nice.
- **Type:** A clean grotesque, set small and consistent, functioning almost
  like a technical spec sheet's labels.
- **Palette:** Muted neutrals (grays, off-whites) plus one functional
  accent color reserved specifically for calls-to-action or the single
  most important data point — never for decoration.
- **Layout:** Grid-locked, modular — content sits in clearly defined
  functional zones (like a well-labeled control panel), each zone doing
  exactly one job.
- **Signature move:** Small, precise labels/captions treated as a real
  design element (not an afterthought) — meta information given the same
  care as the headline.
- **Avoid:** Any flourish that doesn't serve legibility or information
  hierarchy. If you can't explain why an element is there functionally, cut
  it.

### Magazine Editorial
- **Feeling:** Warm, human, story-driven — like a print feature spread, not
  a corporate slide.
- **Type:** A serif for titles (real editorial personality — a Didone or
  slab, not a default serif) paired with a plain sans for body/meta —
  classic magazine pairing.
- **Palette:** Grounded in photography — the palette is *pulled from* the
  hero image rather than imposed on top of it, plus one consistent accent
  for recurring UI elements (category tags, page numbers).
- **Layout:** Asymmetric, image-led — text overlaps or breaks out of a
  strict grid the way a magazine feature does, large pull-quote-style type
  for a single key line.
- **Signature move:** A large pull-quote or oversized single word/number
  breaking out of the body grid as a visual anchor.
- **Avoid:** Stock-photo warmth with no real specificity — the photography
  has to be genuinely good/specific or this style falls apart immediately.

### Zine / Risograph
- **Feeling:** DIY, tactile, a little rebellious — made by a person, not a
  system.
- **Type:** Mix a raw/imperfect display face (something with visible
  character, even slight roughness) with a plain, almost deadpan body font —
  the contrast between "handmade" and "plain" is the joke.
- **Palette:** Riso-inks feel — 2-3 flat, slightly-off colors (not
  pure CMYK) with visible "misregistration" overlap effects where colors
  intentionally overlap imperfectly.
- **Layout:** Collage-like, slightly off-grid on purpose — elements
  overlapping, rotated a few degrees, stickers/stamps aesthetic.
- **Signature move:** A halftone texture or a slightly-misaligned color
  layer (like two-color riso registration drift) on a shape or image.
- **Avoid:** Making it TOO clean — if it looks perfectly vector and crisp,
  it's stopped being zine and started being "clean design pretending to be a
  zine," which reads as fake.

### Brutalist Web
- **Feeling:** Raw, unapologetic, anti-polish — deliberately breaking "good
  design" conventions as the point.
- **Type:** Monospace or a raw system-default-looking face, used at
  aggressive sizes, sometimes overlapping other elements.
- **Palette:** High-contrast, often just black/white/one harsh color (pure
  red, pure yellow) — no soft neutrals.
- **Layout:** Visible grid lines, unstyled-looking borders, elements butted
  right up against the canvas edge with no comfortable margin.
- **Signature move:** Raw HTML-form-control aesthetics used as design
  elements — a plain border, a visible underline, something that looks
  "unstyled" but is precisely placed.
- **Avoid:** Accidentally making it just look broken rather than
  deliberately raw — brutalism only works when the harshness is legible as
  a choice, not a mistake. If a viewer can't tell the difference, it's not
  landing.

### Sagmeister Expressive
- **Feeling:** Bold, personal, a little confrontational — art-directed
  rather than templated, meant to be memorable over comfortable.
- **Type:** Hand-lettered or heavily customized display type for the hero
  statement, treated almost as illustration rather than typesetting.
- **Palette:** Saturated, high-emotion color choices — not afraid of
  "ugly-adjacent" combinations if they serve the statement.
- **Layout:** One dominant idea per slide, executed at full commitment —
  no hedging with secondary content competing for attention.
- **Signature move:** Type-as-image — the words themselves are the visual,
  not a caption under a visual.
- **Avoid:** Diluting the one big idea with supporting bullet points on the
  same slide — this style needs restraint in content even as it's maximal
  in execution.

### Y2K / Futurist
- **Feeling:** Nostalgic-future, glossy, a little chaotic-fun — early-2000s
  optimism about technology, filtered through current retro revival taste.
- **Type:** Chrome/glossy-effect display type or a bubbly rounded sans for
  titles, paired with a technical monospace for meta/labels (the
  "interface" flourish).
- **Palette:** Metallics (silver, chrome gradients), electric blue/purple/
  lime accents, glossy highlights.
- **Layout:** Slightly tilted elements, drop shadows with a glossy sheen,
  UI-chrome details (brackets, corner marks) framing content like a HUD.
- **Signature move:** Corner brackets or crosshair marks framing the main
  content, like a targeting reticle or old software chrome.
- **Avoid:** Overdoing the gloss/chrome to the point of looking like generic
  "AI render" — this is the style most likely to accidentally slide into
  slop if not deliberately restrained. Pick 1-2 Y2K signifiers, not five.

### Atlas Ilustrado
- **Feeling:** Warm, hand-crafted, story-told — like flipping through a
  travel journal a friend actually drew, not a template with a photo dropped
  in. Playful and motivating without being loud.
- **Type:** `BRAND.fonts.handwritten` (Kalam) at poster scale for titles —
  large, white, set over the image with a soft drop shadow for legibility.
  `BRAND.fonts.body` (Inter) for subtitle/footer. `BRAND.fonts.logo`
  (Pacifico) stays reserved for the "Adondepo" wordmark only, never the rest.
- **Palette:** Not a flat CSS palette — an AI-illustrated background image
  per slide (gouache/ink texture, visible brushwork), art-directed to stay
  inside Adondepo's real hex values (petrol `#1a5f7a`, terracotta `#e05a47`,
  gold `#f5b742`, coral `#ff7a6b`, cream `#f8f6f3`) rather than the model's
  own default palette. A dark bottom-third scrim (transparent → petrol-black
  gradient) sits over the image so white text stays legible without hiding
  the art.
- **Layout:** Full-bleed illustrated background, wordmark + slide-counter
  pinned top corners, title/subtitle/footer stacked bottom-left over the
  scrim. One idea per slide (poster, not a card).
- **Signature move:** The illustration itself, scene-matched to that
  specific slide's content (e.g. "someone finding out about a plan too
  late," not an abstract shape) — never a generic "colorful background."
  Every prompt reserves a calm/uncluttered zone (usually the bottom third)
  for the text overlay.
- **Avoid:** Baking any text into the generated image (misspells, wrong
  font, not editable) — text is always real HTML on top. Avoid letting the
  image model default to its own palette instead of Adondepo's brand hexes;
  the art-direction line in the prompt has to be explicit every time.
- **How to reproduce (already built, don't rebuild from scratch):**
  1. Template: `system/ig-carousel/templates/brand-message.ts` (reads a PNG
     from `system/ig-carousel/backgrounds/slide-N.png` per slide, falls back
     to a flat petrol background if missing).
  2. Backgrounds: `system/ig-carousel/generate-backgrounds.ts` — calls
     OpenAI's `gpt-image-1` per slide, one hand-written prompt each (edit the
     `SLIDE_PROMPTS` array for new content; keep the shared `STYLE_DIRECTION`
     string to stay on-brand). Requires `OPENAI_API_KEY` in `.env`
     (git-ignored — see `.env.example` once one exists, or copy the key from
     the sibling `city-activities-api` repo's `.env`).
  3. Content: `system/ig-carousel/brand-input.json` (the `{ slides }` input —
     `title`/`subtitle`/`meta`/`category` per slide).
  4. Run: `npx tsx system/ig-carousel/generate-backgrounds.ts` (regenerates
     backgrounds — costs real money per image, only re-run when content
     actually changes) then `npx tsx system/ig-carousel/render-brand.ts
     --profile adondepo` (composites text over the existing backgrounds,
     free/instant — safe to re-run any time copy changes without touching
     images).
- **Status:** proven once (Adondepo's presentation/onboarding carousel,
  2026-07), not yet adopted as the profile's default style — evaluate again
  before treating it as standard.

### Field.io Motion
- **Feeling:** Precise, technical, quietly kinetic — even as a static image
  it should feel like it's mid-motion.
- **Type:** A clean technical sans, often set in a grid of small repeated
  labels/coordinates alongside the main statement (data-viz aesthetic).
- **Palette:** Near-monochrome with one bright signal color for data
  points/highlights, like a technical diagram or scientific visualization.
- **Layout:** Grid-of-cells structure, small multiples, coordinate/axis
  marks treated as design elements.
- **Signature move:** Small tick marks, coordinate labels, or a
  scatter/grid-of-dots motif that reads as "measured" rather than
  decorative.
- **Avoid:** Using this style for content that isn't actually structured/
  systematic — it looks fake fast if the "data" aesthetic isn't backed by
  a genuinely systematic layout underneath.

## Picking for this project (Adondepo)

Adondepo's actual brand tokens (see `examples/adondepo-brand-spec.md`) —
warm terracotta/gold/coral, petrol blue, Pacifico wordmark, Inter body — lean
naturally toward **Magazine Editorial** (image-led, warm, event-photography
driven) or a warmer take on **Swiss Editorial** (disciplined grid, but with
Adondepo's warm palette instead of black/white). Bauhaus and Brutalist would
fight the brand's warmth; Kenya Hara emptiness would fight the "digest of
many events" density that `list-format` needs to convey. Pitch from the
directions that don't fight the existing brand tokens, not just whatever's
trendy.
