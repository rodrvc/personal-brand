# idea-capture

## Rol
Capturar o generar ideas de contenido para un perfil.

## Lee primero
- `profiles/<perfil>/profile.md`
- `profiles/<perfil>/config.yaml`
- `profiles/<perfil>/ideas/backlog.md`

## Modos
### 1. Capturar
Transforma una idea suelta del usuario en una entrada clara de backlog.

### 2. Generar
Propone 5-10 ideas alineadas con:
- pilares del perfil
- audiencia
- tono
- canal principal

## Output
Agregar ideas a `profiles/<perfil>/ideas/backlog.md` o devolver una lista lista para aprobar.

## Reglas
- una idea = un ángulo claro
- evitar títulos vagos
- incluir trade-off, opinión o aprendizaje real
- no depender de Notion
